# Forecast V1 Beta

현재 관리 버전은 `v1.0.0-beta.2`입니다. 기존 손익현황 전용 대시보드는 `Dashboard v0.1.0`, 추정 산출 구현본은 `Forecast V1 Beta`로 분리하여 보관합니다. 세부 변경 이력과 관리 기준은 `CHANGELOG.md`, `VERSIONING.md`, `config/release.json`에서 확인할 수 있습니다.

확정 Golden Model을 훼손하지 않고 월별 판매·생산·비용 가정을 반영해 추정 손익을 계산하고, 수식과 서식을 유지한 추정 엑셀을 내려받는 최소 웹 애플리케이션입니다.

## 현재 구현 범위

- 상단 메뉴 구조: `손익 현황 / 추정 산출 / 손익 분석 / 데이터 관리`
- `추정 산출`, `손익 분석`, `데이터 관리`가 구현되어 있으며 `손익 현황`은 기존 대시보드 연결 위치입니다.
- `손익 분석`에는 계획·실적·추정 구분과 무관하게 임의의 모형 2개를 비교하는 범용 비교 엔진이 포함됩니다.
- 관리자: 추정 입력, 계산, 검증, 엑셀 다운로드, 결과 확정 공개
- 일반 사용자: 관리자가 마지막으로 확정한 결과만 조회
- Golden Model 원본은 읽기 전용으로 사용하고 매 실행마다 새 엑셀을 생성
- 서버에서 손익을 계산하고 다운로드 엑셀은 원본 수식과 Excel 전체 재계산 설정을 유지
- 엑셀 다운로드는 화면을 재실행하지 않아 현재 로그인 상태를 유지합니다.
- 다운로드 직전에 선택한 추정 월의 3행을 다시 검사해 `추정`으로 표시하고, 나머지 월의 기존 표기는 유지합니다. 파일명에는 생성시각을 넣어 이전 다운로드 파일과 구분합니다.
- 추정 결과에서는 매출원가·매출총이익·판관비·영업이익 금액 바로 옆에 매출액 대비 비율을 괄호로 표시합니다. 매출액에는 비율을 표시하지 않습니다.
- 상세 산출값 표는 결과 화면에서 제외하고 검증 결과만 접힌 영역으로 제공합니다.
- 다운로드 모형에는 `Data` 바로 옆에 `입력반영내역` 시트를 생성합니다. 기준값과 실제로 달라진 판매·생산·MCM·직접 비용입력만 월·구분·항목·기준값·입력값·차이·사유와 함께 기록하며, `이동` 링크로 실제 반영된 `Data` 셀을 바로 열 수 있습니다. 입력에 따라 변동된 수식 셀과 자동 산출 셀은 기록하지 않습니다.

## 추정 입력

### 추정 기준 모형

관리자는 `추정 산출` 화면에서 최신 실적이 반영된 기준 엑셀만 업로드하고 `업로드 파일을 추정 기준으로 적용`할 수 있습니다. 기준연도와 기준 버전은 별도로 입력받지 않습니다.

- 업로드 원본은 별도로 보관하고 추정 산출 시 복사본만 수정합니다.
- 시트 구조, 필수 손익 셀 및 3행 월 구분값을 검증한 파일만 적용합니다.
- 3행에서 1월부터 연속으로 `실적`이 입력된 마지막 월을 실적 마감월로 자동 인식합니다.
- 실적 마감월까지는 추정 기간에서 제외되며 엔진에서도 입력을 거부합니다.
- 실적 마감월 다음 달부터만 시작 월과 종료 월로 선택할 수 있습니다.
- 기준 모형을 교체하면 이전 입력·계산 세션은 초기화하지만 관리자 로그인은 유지합니다.
- 공개 GitHub 배포본에는 회사 실적이 포함된 Golden Model을 넣지 않습니다. 최초 실행 시 관리자가 최신 실적 반영 기준 엑셀을 업로드해야 합니다.

추정연도, 시작 월, 종료 월은 같은 높이의 좁은 드롭다운으로 한 줄에 표시합니다. 1개월 추정은 두 월 드롭다운에 같은 월을 선택합니다. 선택한 월이 늘어나면 판매·생산·MCM·제조경비·판관비 및 가정 입력표의 월별 열이 자동으로 추가됩니다. 열이 화면 폭을 초과하면 표 안에서 좌우로 스크롤합니다.

수량은 천 단위 구분기호로 표시합니다. 원 단위 금액은 반올림하여 소수점 없이 표시하고, 비율은 소수점 첫째 자리까지 `%`로 표시합니다.
표 머리글과 코드·구분·항목·사유 등 텍스트 열은 가운데 정렬하고, 수량·금액·비율 등 숫자 데이터 열은 숫자 정렬을 유지합니다.

### 판매

SW400, SW440, BW400, BW440, LC, FS_SW, FS_BW, FS_TW, UF/MBR, IX, 기타매출의 수량과 매출액을 입력합니다. 판가는 `매출액 ÷ 수량`으로 계산됩니다. IX 수량 단위는 L입니다.

LC 판매수량 중 당월 LC 생산수량까지는 제조제품으로, 초과분은 상품으로 처리합니다. 초과 상품원가는 모형에서 계산된 LC 제조원가 단가를 사용합니다.

### 생산

- 자체 생산: SW400, SW440, BW400, BW440, LC, FS_SW, FS_BW, FS_TW
- MCM(유상사급): SW400, SW440, BW400, BW440

MCM은 모형의 기존 수량 입력셀만 변경합니다. FS 유상사급 원가 취소, MCM 단가, 외주가공비 제외, 노무비·기타경비 포함 로직을 재설계하지 않습니다.

### 제조경비·판관비

대상월 계획 명세를 불러와 제조경비와 판관비의 `추정금액` 기본값을 계획금액과 동일하게 표시합니다. 계획금액 열은 수정할 수 없고, 색상 표식과 옅은 음영으로 표시된 추정금액 열만 입력할 수 있습니다. 사용자는 변경할 항목의 추정금액만 수정하며, 엔진은 `조정액 = 추정금액 - 계획금액`으로 계산해 모형에 반영합니다. 각 표 바로 아래의 `조정 사유`에서 해당 월과 해당 영역의 항목을 선택해 필요한 건만 저장합니다. 저장된 사유는 목록에서 직접 수정하거나 삭제할 수 있습니다.

판관비 항목은 `판매비_항목명`, `일반관리비_항목명` 형식으로 구분하며, 조정 사유 목록과 내려받은 모형의 `입력반영내역`에도 같은 명칭을 사용합니다.

### 신사업

- UF/MBR·IX 상품원가율: 각각 기본 85%, 수정 가능
- UF/MBR·IX 운반비율: 각각 기본 5%, 수정 가능
- IX 포장비: `IX 수량(L) ÷ 포장단위(기본 25L) × 포장단가(기본 380원)`
- 신사업 상품원가는 모형에 자동 반영하지 않으므로 화면의 산출금액을 확인해 별도로 반영해야 합니다.
- 상품원가율 바로 아래에 신사업 상품원가, 운반비율 바로 아래에 신사업 운반비, IX 포장 가정 바로 아래에 IX 포장비를 하나의 월별 동적 표 블록으로 표시합니다.
- 신사업 운반비와 IX 포장비의 월별 `판관비 조정 사유 반영` 버튼은 해당 금액을 판관비 조정 사유에 기록합니다. 사용자는 그 금액을 확인한 뒤 판관비 추정금액을 직접 수정합니다.
- 제품 폐기손실·진부화 평가손실은 신사업 가정과 분리하여 `매출원가 조정`에서 각각 입력합니다.

### 북미/남미 관세

- 계획 매출액과 추정 매출액을 별도로 입력합니다.
- 각 월을 하나의 세로 영역으로 묶어 계획 매출액·추정 매출액·관세 적용 매출 비중·관세율을 함께 입력합니다.
- 계획 관세: `계획 지역 매출 × 관세 적용 대상 매출 비중(기본 10%) × 관세율(기본 13%)`
- 추정 관세: `추정 지역 매출 × 관세 적용 대상 매출 비중 × 관세율`
- `추정 관세 - 계획 관세`는 판매비 운반비 조정 참고금액으로만 계산하며 모형에는 자동 반영하지 않습니다.
- 월별 `판관비 조정 사유 반영` 버튼은 `계획 대비 미주지역 매출 변동으로 인한 관세 금액 반영 : 금액`을 판매비 운반비의 판관비 조정 사유에 기록합니다. 사용자는 그 금액을 확인한 뒤 판매비 운반비 추정금액을 직접 수정합니다.
- 관세 결과표는 행을 계획 관세·추정 관세·판매비 운반비 조정액으로 두고, 선택한 월을 열로 표시합니다.
- 원재료 관세 환급: `(전공정 재료비 수불부 생산출고액 + 후공정 재료비 수불부 생산출고액) × 환급률(기본 1.3%)`. 모형 산출값 선택 시 해당 기준을 적용해 1246행에 음수로 반영합니다.

### 매출원가 조정

- 제품 폐기손실: 제품 매출원가 가산
- 제품 진부화 평가손실: 제품 매출원가 가산
- 제품 폐기손실은 1248행, 진부화 평가손실은 1250행에 계획값 대비 조정액으로 반영합니다.
- 각 항목은 금액과 사유를 기록하고 별도 항목으로 표시합니다.

원재료 투입비 기준은 월별 라디오 버튼에서 `모형 산출값` 또는 `구매팀 예상 금액` 중 선택합니다. 구매팀 예상 금액을 선택하면 `구매팀 추정 투입비`를 입력합니다. 추정 생산수량을 먼저 모형에 반영해 산출된 전공정·후공정 생산출고 원재료비 비율로 구매팀 추정 총액을 배부하며, 배부된 금액은 각각 전공정 211행과 후공정 690행에 반영됩니다. 관세 환급금은 배부 전 구매팀 추정 총액에 환급률을 적용합니다. 전·후공정 배부금액, 적용 비율과 관세 환급금은 `입력반영내역`에 기록됩니다.

## 범용 모형 비교

`데이터 관리`에서 모형명, 계획/실적/추정 구분, 기준기간, 작성일, 버전, 확정 여부와 함께 xlsx 모형을 등록합니다. 모형 구분은 표시용 메타데이터이며 비교 조합을 제한하지 않습니다. 북미/남미 관세 입력은 데이터 관리에서 제공하지 않고 `추정 산출`에서만 관리합니다.

`손익 분석`에서 체크박스로 정확히 두 모형을 선택합니다. 두 개가 선택되면 나머지 모형은 선택할 수 없으며, 기준 모형과 비교 모형을 서로 전환할 수 있습니다. 모든 증감액은 다음 식을 사용합니다.

```text
증감액 = 비교 모형 - 기준 모형
```

두 모형의 기준기간에 공통으로 포함된 월, 완전한 분기, 누계 및 잔여연간만 선택할 수 있습니다. 비교 결과에는 다음 항목이 포함됩니다.

- 손익계산서 증감
- 제품별 매출액·수량·기간 가중평균 판가
- 생산량과 MCM(유상사급) 수량
- 원재료비, 노무비, 외주가공비, 기타경비 및 제조경비
- 판매비, 일반관리비, 폐기손실, 진부화 평가손실
- 판관비에 사용자가 직접 반영한 운반비 조정과 모형의 원재료 관세 환급금
- 영업이익 증감, 세부 변동효과 합계 및 잔여차이

계획 대비 실적, 전추정 대비 현추정 등 조합별 별도 계산식은 없으며 동일한 비교 엔진을 사용합니다.

## 실행 방법

Python 3.11 이상 환경에서 다음을 실행합니다.

가장 간단한 방법은 `start_forecast.cmd`를 실행하는 것입니다. PowerShell을 사용하지 않고 Python이 앱을 직접 실행합니다. 실행 창에서 일반 사용자 코드와 관리자 코드를 차례로 물어보며, 입력한 문자는 화면에 표시되지 않습니다.

```text
start_forecast.cmd 더블클릭
→ 일반 사용자 접속 코드 입력
→ 관리자 접속 코드 입력
→ 웹 화면 자동 실행
```

```powershell
python -m pip install -r requirements.txt
$env:VIEWER_CODE="조회자 접속코드"
$env:ADMIN_CODE="관리자 접속코드"
streamlit run app.py
```

Windows에서는 접속코드를 명령행 인자로 전달하는 실행 스크립트를 사용할 수 있습니다.

```powershell
.\run.ps1 -ViewerCode "조회자코드" -AdminCode "관리자코드" -Port 8501
```

테스트:

```powershell
python -m unittest discover -s tests -v
```

## 모형 보호 및 검증

- 설정에 지정된 입력셀만 변경
- 수식 셀은 기본적으로 덮어쓰기 금지
- 매출 입력처럼 원 모형에서 계획값이 수식으로 들어간 지정 셀만 명시적 예외 허용
- 원재료 및 가공비 계획 배부율 누락·합계 검증
- `매출 - 매출원가 - 판관비 = 영업이익` 검증
- 모든 반영 내역에 셀, 기존값, 적용값, 출처, 사유, 수식 예외 여부 기록
- 다운로드 파일에 Excel 전체 재계산 플래그 설정

## 확인 필요사항 및 현재 제한

1. 북미/남미 관세는 Golden Model의 `세금과공과`를 사용하지 않습니다. 계산된 관세 증감은 참고금액과 사유 초안만 제공하며, 판매비 운반비 반영액은 사용자가 판관비 추정금액에서 직접 결정합니다. 데이터 관리에는 별도 관세 입력란을 두지 않습니다.
2. UF/MBR과 IX는 웹에서 별도 관리하지만 Golden Model에는 신사업 합계 매출행만 있습니다. 상품원가·운반비·포장비 참고 계산값은 자동 반영하지 않으며, 사용자가 매출원가 또는 판관비 추정금액으로 직접 반영합니다.
3. 기타매출 수량은 단위가 정의되지 않아 매출액만 반영합니다.
4. 수식 계산기는 현재 Golden Model에서 확인된 `SUM`, `IF`, `IFERROR`, `SUMIFS`와 산술·비교식을 지원합니다. 모형에 새 Excel 함수가 추가되면 계산기 지원 또는 매핑 검토가 필요합니다.
5. LC 초과 판단 기준은 `Forecast LC 판매수량 - Forecast LC 생산수량`입니다. 향후 기초재고나 별도 조달계획을 기준에 넣으려면 업무 규칙을 변경해야 합니다.
6. 초기 운영에서는 다운로드 파일을 Excel로 열어 전체 재계산 후 웹 결과와 주요 손익을 대사하고, 안정화 후 자동 확정 범위를 확대하는 것을 권장합니다.
7. Golden Model 원본에는 기존 오류 표시 2건(`F598`, 구분손익 영역의 원본 수식 1건)이 남아 있습니다. 생성 검증본에서도 동일하게 확인되며 Forecast V1이 새로 만든 오류는 아닙니다. 해당 원본 오류는 Golden Model 변경 승인 후 별도 정리 대상입니다.
