# 계획 대비 손익분석 V1 — 1차 구현 보고

## 1. 현재 Forecast V1 구조 점검

기존 프로젝트는 `forecast/engine.py`가 Golden Model 복사본에 추정 입력을 반영하고, `forecast/workbook.py`가 수식 보호·재계산·입력 로그를 담당합니다. `forecast/comparison.py`에는 임의의 두 모형을 비교하는 총액 비교 기능이 있으나 수량·Mix·판가·환율·원부재료·제조경비 효과를 분해하는 엔진은 없었습니다.

분석 V1 계산 엔진은 기존 Forecast writer와 분리해 `forecast/analysis/`에 추가했습니다. 기존 추정 산출은 그대로 유지하면서, 판매효과부터 Streamlit `손익 분석` 화면에 단계적으로 연결했습니다.

## 2. 참고 엑셀에서 확인한 핵심 산식

참고 파일: `판가_환율_분석로직_v4_원부재료_V1_반영.xlsx`

- 원부재료 총효과: 제품 타입별 `(기준 생산출고 원단위 - 비교 생산출고 원단위) × 비교 판매량`
- FS 판매 대응량은 길이, SW·BW·LC는 PCS
- 부직포 엔화 효과: `비교 판매대응 투입길이 × 기준 JPY 원단위 × (기준 원/JPY - 비교 원/JPY)`
- 엔화 제외 원부재료 원단위 효과: `원부재료 총효과 - 부직포 엔화 효과`
- 제조 변동비: 전·후공정별 조업도 효과와 원단위 효과 분리
- 제조 고정비: 기준 배부금액과 비교 배부금액의 차이
- 제조경비 손익실현 효과: 발생기준 효과 × 비교 모형 재고실현율
- 판매운반비: 관세를 제외한 운반비를 수량효과와 원단위효과로 분리
- 운반비 원단위효과는 판매단가 효과에 포함하고 관세는 별도 효과
- 판관비 변동 항목은 브랜드사용료·포장비, 나머지는 고정비로 분리

참고 엑셀의 설명 문구 중 변동 판관비 범위를 넓게 적은 셀이 있으나, 실제 상세 계산 구간과 확정 업무명세에 따라 V1 설정은 브랜드사용료·포장비만 변동으로 고정했습니다.

## 4. 공통 데이터 스키마

단일 반복행에 모든 데이터를 중복시키지 않고 다음 6개 표로 정규화합니다.

- `products`: 모형 메타데이터, 월, 제품코드·제품군, 판매수량·길이·금액, 제품원가, 생산수량·길이, 원부재료비, 부직포비, 매출환율, JPY 환율
- `manufacturing_expenses`: 월, 제조경비 계정, 금액, 전·후공정 배부율
- `sga_expenses`: 월, 판관비 계정, 금액
- `activities`: FS 생산길이, SW+BW 생산 PCS, 판매운반비 활동량, 당기투입제조원가, 재고실현율, 직접입력 관세
- `pnl`: 매출액, 매출원가, 영업이익
- `direct_effects`: 폐기·진부화·관세환급 등 직접 손익조정

모든 표에는 `scenario_id`, `scenario_type`, `version`을 공통으로 붙일 수 있으며 `AnalysisScenario.to_common_tables()`가 이를 보장합니다.

## 5. 구현된 효과와 부호

모든 효과는 손익 개선을 양수, 악화를 음수로 반환합니다.

- 판매: 수량, Mix, 순수 판가, 매출환율, 관세 제외 운반비 수량·원단위, 관세
- 원부재료: 총효과, 부직포 엔화, 엔화 제외 원단위
- 제조경비: 전공정 조업도·원단위, 후공정 조업도·원단위, 전·후공정 고정비, 발생효과, 손익실현 효과
- 판관비: 브랜드사용료·포장비 변동효과, 기타 고정효과. 판매운반비와 관세는 중복 방지를 위해 제외
- 직접 조정: 기준 금액 - 비교 금액으로 손익효과 계산
- 정합성: `비교 영업이익 - 기준 영업이익 - 분석효과 합계 = 잔여차이`

## 7. 1.1 확정 규칙 반영

- 제조경비 조업도는 SAP 수불부 생산입고로 통일했습니다. 전공정은 FS 생산입고 길이, 후공정은 LC를 제외한 SW+BW 생산입고 PCS입니다.
- MES 생산실적은 제조경비 계산에 사용하지 않고 `MES-SAP` 차이표에만 제공합니다.
- MCM(유상사급) 금액은 회계 분류대로 원부재료에 전액 유지합니다. MCM 수량은 외주가공비 원단위 분모에서 제외합니다.
- MCM 영향은 원부재료 총효과의 상세 원인으로만 제공하며 영업이익 브리지에는 독립 항목으로 추가하지 않습니다.
- 원부재료 상세는 손익효과 부호 기준으로 `총효과 = 부직포 엔화 + MCM + 기타 원부재료`가 성립합니다.
- 판매단가 효과는 `표시 판매단가 효과 + 관세 제외 운반비 원단위 효과`이며 관세는 직접 입력 별도 효과입니다.
- 재고실현율은 100%를 초과해도 상한을 두지 않습니다.
- 판매효과 제품군에 신사업을 추가했습니다.

## 8. 검증 결과

총 29개 단위·회귀 테스트가 통과했습니다. 추가된 필수 사례는 다음과 같습니다.

- MCM 물량 증가 및 일반 외주가공 대상 물량 감소
- MCM 출고금액의 원부재료 전액 포함
- 외주가공비 원단위 분모에서 MCM 제외
- MCM 효과의 영업이익 브리지 중복 방지
- 원부재료 총효과와 엔화·MCM·기타 상세 정합성
- MES와 SAP 수량이 다른 경우에도 SAP 기준 제조경비 계산
- 재고실현율 100% 초과 적용 및 전체 Forecast 회귀검증

## 9. 다음 연결 전 확인 필요사항

판매효과에 필요한 SW·BW·LC·FS 수량·매출액·매출원가는 Golden Model의 Item별 구분손익 합계 행을 확인해 `config/model_mapping.json`에 명시적으로 연결했습니다. 아래 나머지 항목은 셀 주소를 추정해 하드코딩하지 않았으며 `config/analysis_v1.json`에 `explicit_mapping_required`로 남겨 두었습니다.

- 제품별 매출통화·매출환율
- 부직포 생산출고금액·생산길이·판매대응 투입길이·JPY 환율
- 제조경비 계정별 금액과 노무비/외주가공비/기타경비 배부율
- 판관비 계정별 금액과 판매운반비 활동량
- 당기투입제조원가 및 직접입력 관세
- MCM 자재코드 또는 생산유형 매핑
- SAP 생산입고 수량·길이와 선택적 MES 생산실적 매핑

다음 단계는 원부재료·생산(제조경비)·판관비 항목의 Golden Model용 상세 매핑을 추가하고, 해당 필드를 공통 스키마로 내보내는 읽기 전용 Excel 어댑터를 구현하는 것입니다. 각 영역의 엑셀 대사가 통과한 뒤 현재 마련된 세 효과 탭에 계산 결과를 연결합니다.
