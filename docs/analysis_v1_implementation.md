# 손익분석 V1 구현 기준

## 데이터 흐름

손익분석은 다음 단일 흐름을 사용한다.

`Golden Model → GoldenAnalysisAdapter → deterministic analysis engine → ComparisonResult → presentation view → Streamlit / 검증 Excel / AI Fact Pack`

Streamlit은 Golden Model 셀을 읽거나 손익효과를 자체 계산하지 않는다. 원 단위 계산값은 Result까지 유지하고 화면과 AI Fact Pack의 마지막 표시 단계에서만 백만원으로 변환한다.

## Golden Model 원천 매핑

원천 행은 `config/model_mapping.json`의 `analysis_adapter`에 명시한다.

- 엔화환율: 9행, 단위 KRW/JPY
- 전공정 부직포 생산출고: 205~207행(수량·금액·단가)
- 부직포 제외 전공정 원재료 생산출고: 208~210행(수량·금액·단가)
- 후공정 원재료 생산출고: 684~699행
- 제조경비 명세: 289~319행
- 전공정 가공비 투입비율: 345행 노무비, 346행 외주가공비, 347행 기타경비

제품군별 원재료 원단위는 위 생산출고 원천금액과 Golden Model의 제품군 배부율·생산량을 사용한다. 완제품 제조원가 합계에서 원재료를 역추정하지 않는다. 전공정 원재료 합계는 211행, 후공정 원재료 합계는 699행을 최종 원천으로 사용하여 Forecast가 합계 행에 직접 반영한 추가 원재료도 누락하지 않는다. 부직포 분해는 205~207행을 사용하고, 합계와의 차이는 부직포 제외 원재료 효과에 포함해 3요소 정합성을 유지한다. 제조경비는 전·후공정 별도 원천금액이 없으므로 289~319행 계정 총액에 기준 모형의 345~347행 비율을 곱해 전공정 금액을 구하고, 나머지를 후공정 금액으로 사용한다. 동일한 기준 비율을 기준·비교 모형에 일관 적용한다.

## 확정 계산 정책

- 모든 증감은 `비교 - 기준`, 모든 손익효과는 `+ 영업이익 개선 / - 영업이익 악화`다.
- 원부재료 총효과는 제품군별 `(기준 원단위 - 비교 원단위) × 비교 판매수량`의 합이다.
- 원부재료는 `부직포 단가효과(환율 제외) + 부직포 엔화효과 + 부직포 제외 원재료 효과`로만 분해한다.
- MCM은 원재료 원가에 포함하되 독립 손익효과나 AI 원인으로 만들지 않는다. 수율·사용량 효과도 V1에서 만들지 않는다.
- 전공정 조업도는 FS SAP 생산입고 길이(m), 후공정은 SW+BW+LC SAP 생산입고 PCS 합계다.
- MCM 수량은 외주가공비 후공정 조업도에서 제외한다.
- 변동 제조경비는 수도광열비·소모품비·외주가공비·원자재운반비이며 조업도효과와 원단위효과로 분해한다.
- 나머지 제조경비 계정은 고정비로 처리하며 `기준금액 - 비교금액`을 적용한다.
- 재고실현율은 `매출원가 / 당기투입 제조원가`이며 100% 상한을 두지 않는다.
- 변동 판관비는 브랜드사용료·포장비다. 나머지 일반 판관비는 고정 판관비다.
- 판매비 구역의 고객배송 운반비는 실제 금액을 표시하지만 Bridge는 판매효과로 연결해 판관비와 중복 계산하지 않는다.
- V1 고객배송 운반비 효과는 `Base 관세 제외 운반비 - Comparison 관세 제외 운반비`다. 제품군별 배부 source가 없으므로 PCS와 m를 합산한 분모나 원단위 분해를 사용하지 않는다.
- 호환 payload의 `transport_quantity_effect`는 0, `transport_unit_effect`는 canonical `transport_effect`와 같다. 합계에는 판매단가 효과를 통해 한 번만 반영한다.
- 관세는 외부효과/관세효과로 정확히 한 번만 반영한다.
- 정합성은 `effects_total + residual = operating_profit_delta`로 검증하며 residual을 기타효과에 숨기지 않는다.

## 화면과 출력

손익분석 탭 순서는 `종합 / 판매효과 / 원부재료 / 제조경비 / 판관비 / AI 분석`이다. 제조경비와 판관비 상세는 Golden Model 계정을 동적으로 읽어 개별 행으로 표시하며 ‘기타 제조경비’ 또는 ‘기타 판관비’로 합치지 않는다.

검증 Excel은 화면과 동일한 Result를 사용해 제품군별 원부재료 3요소, 제조경비 계정별 배부·효과, 판관비 계정별 Bridge 위치와 원천셀을 기록한다. AI는 API를 호출하지 않으며 동일 Result를 백만원 Fact Pack으로 변환한 뒤 사용자가 버튼을 눌렀을 때만 ChatGPT용 프롬프트를 만든다. 정합성 CHECK 상태에서는 생성 버튼을 비활성화한다.
